# avina

وب‌سایت معرفی و نمونه‌کار فارسی برای برند **FastWeb96** و طراح **rezaakbari**. پروژه کاملاً استاتیک است: HTML، CSS، JavaScript، SVG و تصویرهای WebP؛ بدون backend، دیتابیس، secret یا فرایند build. منو، فیلتر نمونه‌کارها، تعامل‌های سبک و اعتبارسنجی فرم سمت مرورگر اجرا می‌شوند.

## ساختار پروژه

```text
avina/
├── app.config.ts
├── index.html
├── README.md
├── ASSET_SOURCES.md
├── plan.md
├── TODO.md
├── .gitignore
├── manus-routes.json
└── assets/
    ├── css/style.css
    ├── js/main.js
    ├── images/
    │   ├── hero/.gitkeep
    │   ├── services/
    │   ├── portfolio/
    │   └── icons/favicon.svg
    └── fonts/.gitkeep
```

`index.html` صفحهٔ اصلی، metadata و محتوای معنایی را در خود دارد. استایل و رفتار در `assets/css/style.css` و `assets/js/main.js` قرار دارند. `app.config.ts` فقط metadata لوگوی پروژهٔ Manus را نگه می‌دارد و برای GitHub Pages یا اجرای وب‌سایت لازم نیست. `plan.md` و `TODO.md` ثبت تصمیم‌ها و وضعیت پروژه‌اند؛ `ASSET_SOURCES.md` منابع عکس‌ها و یادداشت حقوق استفاده را فهرست می‌کند. تصاویر سرویس‌ها و نمونه‌کارها در پوشه‌های جداگانه‌اند تا به‌سادگی تعویض شوند. فونت Vazirmatn در صورت اتصال به اینترنت از Google Fonts بارگذاری می‌شود؛ در صورت قطع آن، فونت‌های سیستمی فارسی fallback هستند. سایت به این درخواست اختیاری برای عملکرد اصلی وابسته نیست.

## اجرای محلی

برای مشاهدهٔ نسخهٔ ایستا، مخزن را دریافت کنید و از ریشهٔ پروژه یکی از دستورهای زیر را اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس در مرورگر `http://localhost:8000/` را باز کنید. نیازی به `npm install`، build یا backend نیست. بازکردن مستقیم `index.html` نیز برای محتوای پایه ممکن است؛ برای مسیرهای نسبی و بررسی دقیق، HTTP server محلی پیشنهاد می‌شود.

## انتشار با GitHub Pages

این پروژه برای repository عمومی [rezaa63/avina](https://github.com/rezaa63/avina) آماده شده است. مخزن از branch `main` و پوشهٔ ریشه (`/`) سرو می‌شود و Pages به build یا workflow جداگانه نیاز ندارد.

برای تنظیم یا بررسی انتشار در GitHub، به **Settings → Pages** بروید. در **Build and deployment** گزینهٔ **Deploy from a branch**، branch `main` و پوشهٔ `/ (root)` را انتخاب کنید. پس از پایان انتشار، نشانی پروژه این است: <https://rezaa63.github.io/avina/>.

Canonical، Open Graph و JSON-LD در `index.html` از قبل به نشانی واقعی `https://rezaa63.github.io/avina/` اشاره می‌کنند. اگر مخزن به مالک دیگری منتقل شد یا دامنهٔ سفارشی اضافه شد، canonical، `og:url`، `og:image` و فیلد `url` در structured data را هم‌زمان به‌روزرسانی کنید. دامنه و آدرس‌های شبکه‌های اجتماعی در نسخهٔ پیش‌فرض نمونه‌اند و برای اتصال به حساب‌های شخصی باید اصلاح شوند. همهٔ مسیرهای فایل‌های داخلی نسبی و با `./` آغاز می‌شوند تا وب‌سایت در زیرمسیر repository هم درست کار کند.

## ویرایش محتوا و تنظیمات

- **متن‌ها:** محتوای بخش‌ها مستقیماً در `index.html` است. ساختار headingها، label فیلدها و metadata را متناسب با محتوا حفظ کنید.
- **شماره تماس:** مقدار `phone` در شیء `SITE_CONFIG` در بالای `assets/js/main.js` را تغییر دهید. شمارهٔ نمایش‌داده‌شدهٔ HTML نیز در همان فایل در بخش contact و footer نوشته شده؛ بعد از ویرایش، همهٔ محل‌ها و لینک‌های `tel:` را بررسی کنید.
- **لینک شبکه‌های اجتماعی:** آرایهٔ `socials` در بالای `assets/js/main.js` را تغییر دهید. فقط Telegram، Instagram، Rubika و Bale در نسخهٔ پیش‌فرض هستند. نشانی‌های فعلی به صفحهٔ اصلی پلتفرم‌ها می‌روند؛ برای اتصال به حساب خود، URL هرکدام را با نشانی profile خود جایگزین کنید. WhatsApp عمداً استفاده نشده است.
- **واترمارک و اعتبار طراح:** رشتهٔ `rezaakbari` در `SITE_CONFIG.designer` و متن‌های ثابت HTML قرار دارد. کلاس مستقل `.personal-watermark` در CSS اندازه، رنگ، opacity و موقعیت watermarkها را کنترل می‌کند؛ متن watermark روی Portfolio از تنظیم JS ساخته می‌شود. عبارت Footer را با حفظ فرمت `Designed by rezaakbari` ویرایش کنید.
- **تصاویر:** فایل‌ها WebP هستند. برای سرویس‌ها، فایل‌های همنام در `assets/images/services/` را جایگزین کنید و ابعاد/قاب را در CSS تنظیم کنید. برای کارت‌های Portfolio، تصاویر را در `assets/images/portfolio/` بگذارید، سپس مسیر و متن جایگزین را در آرایهٔ `projects` داخل `assets/js/main.js` به‌روزرسانی کنید. فایل جدید را فشرده کنید و `alt` توصیفی و دقیق بنویسید. تصاویر موجود نمونهٔ نمایشی‌اند؛ منبع و وضعیت مجوز آن‌ها در `ASSET_SOURCES.md` درج شده است. پیش از استفادهٔ تجاری، مجوز و حقوق انتشار را بررسی کنید یا تصاویر دارای مجوز خود را جایگزین کنید.
- **افزودن Portfolio:** در آرایهٔ `projects` در `main.js` یک شیء با `name`, `category`, `key`, `description`, `image`, `alt` اضافه کنید؛ تصویر متناظر را در `assets/images/portfolio/` ذخیره و فیلتر `data-filter` متناظر را در `index.html` اضافه کنید. شمارنده به‌صورت خودکار تعداد موارد قابل‌مشاهده را نشان می‌دهد؛ متن ثابت `۰۶ پروژه` بالای لیست در HTML را می‌توان حذف یا با متن راهنما جایگزین کرد.
- **شهادت مشتریان:** سه کارت بخش نظرات در `index.html` متن نمونه هستند. عبارت‌های نام، متن و عنوان هرکارت را با بازخورد واقعی و دارای اجازهٔ انتشار عوض کنید.
- **فرم سفارش:** این نسخه ورودی‌ها را فقط داخل مرورگر اعتبارسنجی می‌کند؛ فرم اطلاعات را به سرور نمی‌فرستد و ذخیره نمی‌کند. بعد از اعتبارسنجی، شماره تماس را برای پیگیری نشان می‌دهد. برای دریافت آنلاین سفارش، باید بعداً handler سمت client را با API/WordPress خودتان جایگزین کنید؛ secrets را داخل JavaScript عمومی قرار ندهید.
- **Canonical، OG و favicon:** عنوان و توضیح SEO در `<head>` فایل `index.html` هستند. URLها برای `rezaa63/avina` تنظیم شده‌اند. نشان SVG در `assets/images/icons/favicon.svg` قابل‌تعویض است.

## نکتهٔ دسترسی و حرکت

منوی موبایل، فیلترهای Portfolio و فرم با JavaScript کنترل می‌شوند. برای کاهش حرکت سیستم، وب‌سایت به `prefers-reduced-motion` احترام می‌گذارد. تصاویر غیرضروری lazy-load هستند؛ تصاویر بالای صفحه را در صورت نیاز بهینه کنید تا بارگذاری اولیه سبک بماند.
